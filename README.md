# [NAME] — Portfolio 2026

株式会社VへのPM／ディレクター応募を主目的とした、単一ページのインタラクティブポートフォリオです。

## Content updates

作品、カテゴリー、経歴、制作プロセスのplaceholderは `app/portfolio-data.ts` にまとめています。実データへ置き換える際は、UIコンポーネントを変更せずこのファイルを更新します。

画像・動画を追加する場合は `public/images/`、`public/videos/` へ配置してください。未提供の実績、数値、経歴は意図的に創作していません。

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
```

## Privacy

応募者向けの限定URLとして使用する想定のため、ページには `noindex, nofollow` を設定しています。パスワード保護は行いません。
